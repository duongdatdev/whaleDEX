## Coverage rules

- Each canonical FR/NFR ID appears exactly once; no separate chapter numbering scheme.
- Every goal G-01..G-04 maps to requirements, stories and tests.
- A linked test file proves only the behaviour it executes. Config tests do not prove live RPC, wallet, quote or mainnet readiness.
- Replace planned descriptions with exact test/run/review evidence in the implementing change.
- Update PRD, stories, lab examples and matrix together when scope changes.
- OBS-* and H-* in Chapter 3 are fictional observations or hypotheses, not real research evidence.

## Current audit

FR-CONFIG-01 is implemented at a13203e. Explorer metadata and chain validation are enabling parts of FR-EXPLORER-01/NFR-SEC-02. All wallet, quote, routing, approval, swap and runtime transaction capabilities remain unimplemented. Mainnet readiness requires separate evidence for BSC, Ethereum, Base, Polygon PoS and Arbitrum One.
